# BioAvanceD UI Gold Demo (Fase 0)

Live demo **isolada** do frontend de produção. Layout TailAdmin **Sectioned** + brand BioAvanceD (`#371667`, logo CORE).

## Rodar

```bash
cd frontend-ui-demo
npm install
npm run dev
```

Abra **http://localhost:5174/**

- `/` — mapa de **todas** as rotas de tela  
- Sidebar — navegação por grupos  
- Destaques: Dashboard, Facility (temperatura + CryoBox), Construtor de TCLE  

Dados são mock (sem API). **Não** altera `frontend/` até aprovação.
