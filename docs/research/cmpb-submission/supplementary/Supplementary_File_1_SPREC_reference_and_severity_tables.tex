\noindent\footnotesize
\textit{Note.} The severity values shown in this supplementary table define \(s_i(x_i)\), not the final axis penalty. The effective penalty for each SPREC-derived axis is calculated as \(p_i^{(k)} = W_i^{(k)} \cdot s_i(x_i)\). Therefore, \(W_i^{(k)}\) defines the biological-operational priority of the axis, whereas \(s_i(x_i)\) defines the severity of the observed SPREC-coded condition within that axis. For temporal axes, \(s_i(x_i)\) follows the time intervals defined in SPREC 2.0. For non-temporal axes, \(s_i(x_i)\) follows workflow compatibility, preservation stability, and biological-operational relevance. Conditional entries were resolved according to the intended analytical workflow documented for the specimen. Conditions compatible with the intended workflow but less optimal than reference cryogenic or processing conditions were assigned low severity, whereas conditions incompatible with the intended workflow or missing an expected processing step were assigned maximum severity. Values marked as ``Not scored'' do not represent zero severity or absence of risk; they indicate that the coded condition is unknown, missing, invalid, unrecognized, semantically incompatible, locally unresolved, or insufficiently documented for additive severity assignment. These conditions are therefore evaluated through the non-compensable governance gate rather than through RCS penalty scoring.
