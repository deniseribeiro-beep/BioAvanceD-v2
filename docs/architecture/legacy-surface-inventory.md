# Legacy Surface Inventory

Branch: `feature/docker-e2e-backend-integration`
Date: `2026-11-17`
Requirements: RNF028 C6 (`docs/extracted-v2.0.0/requisitos.md`). Issue #1574.

A legacy surface is code, a collection or a document that is superseded by a newer module doing the same job; or that no route or service reaches; or that is mid-migration, with the old and the new both present; or that is a v1.3.0 element `docs/extracted-v2.0.0/dict-MIGRACAO_V1_3_PARA_V2.md` marks deprecated, replaced or renamed. A surface found legacy is added to this inventory in the same change that finds it, and a row's plan changes with the decision that changes it (`docs/decisions/2026-11-17-rnf028-legacy-surface-inventory.md`).

Status is one of `retired`, `migrating`, `kept as history`, `listed, not moved` or `open`. Plan is the next step, or `none:` and why. Guard is the architecture test under `api/backend/tests/architecture/` that keeps the surface from growing, or `none`. This inventory supersedes `docs/architecture/canonical-active-surface.md`.
