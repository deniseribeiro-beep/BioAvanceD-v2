# 03_INTEROPERABILIDADE

Matriz de interoperabilidade e mapeamentos

Relações descritivas entre o modelo canônico e padrões externos. Todos os contratos de transformação são preparados na Fase 1; sua utilização ocorre conforme as cargas das Fases 2 e 3. Nenhum mapeamento implica equivalência automática sem validação.
