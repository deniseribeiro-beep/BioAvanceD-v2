# Qualidade pré-analítica, SPREC e RCS-GOV

O SPREC descreve variáveis pré-analíticas relevantes para biospecímenes. O RCS-GOV é um mecanismo determinístico baseado em regras para qualificação operacional de amostras.

## Regras de interpretação

- não é modelo de machine learning;
- não produz diagnóstico;
- não usa probabilidade clínica;
- cada resultado deve indicar versão da regra, entradas utilizadas, penalidades, classificação e justificativas;
- falhas de governança não compensáveis podem impedir classificação favorável mesmo quando a soma numérica é alta;
- resultados devem ser reproduzíveis para as mesmas entradas e versão de regras.

## Uso operacional

A classificação pode apoiar quarentena, liberação condicionada, revisão de qualidade e transparência sobre variáveis pré-analíticas. A decisão final deve respeitar consentimento, políticas institucionais e escopo de uso.
